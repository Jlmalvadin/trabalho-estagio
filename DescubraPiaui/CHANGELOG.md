## 📝 Notas de Versão

### Como atualizar de v1.0.0 para v2.0.0

1. **Backup do points.json atual**:
   ```bash
   cp data/points.json data/points.backup.json
   ```

2. **Atualizar arquivos**:
   ```bash
   git pull origin main
   ```

3. **Reinstalar dependências** (se necessário):
   ```bash
   npm install
   ```

4. **Verificar mudanças**:
   - ✅ Componentes atualizados automaticamente
   - ✅ Estilos CSS expandidos
   - ✅ Novos pontos adicionados

5. **Restart do servidor**:
   ```bash
   npm run dev
   ```

### Breaking Changes
Nenhuma! A v2.0.0 é 100% compatível com v1.0.0. 🎉
